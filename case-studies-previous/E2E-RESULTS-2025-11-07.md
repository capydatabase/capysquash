## Bugs Identified

### BUG #1: Docker Container Timeout (CRITICAL)

**Status**: ❌ Blocks E2E validation
**Severity**: High
**Frequency**: 100% (all 3 projects)

#### Description
All validation attempts fail with identical error:
```
❌ Validation failed: [ERROR:VALIDATION] code:DATABASE_NOT_ACCESSIBLE
PostgreSQL not ready suggestion: Increase ContainerReadyTimeout in config
or check container logs for PostgreSQL startup errors
   Inner error: [ERROR:VALIDATION] code:DATABASE_NOT_ACCESSIBLE
timeout waiting for PostgreSQL after 1m0s
```

#### Root Cause
The default `container_ready_timeout` of 60 seconds is insufficient for PostgreSQL containers to become fully ready, especially when:
- Loading multiple extensions (pgcrypto, postgis, pg_trgm, etc.)
- Initializing complex schemas
- System is under moderate load

#### Impact
- Prevents automated validation of squashed migrations
- Blocks end-to-end testing workflow
- Users cannot verify schema equivalence without manual intervention
- CI/CD pipelines may fail unpredictably

#### Current Configuration
```json
"validation": {
  "mode": "TWO_DATABASES",
  "docker_image": "postgres:15",
  "timeout_seconds": 120,
  "container_ready_timeout": 30  // Too short!
}
```

#### Proposed Solution
Increase the container ready timeout and add retry logic:

```go
// internal/validation/validator.go

const (
    DefaultContainerReadyTimeout = 90 * time.Second  // Increased from 30s
    MaxRetries                   = 3
    RetryBackoff                 = 5 * time.Second
)

func (v *Validator) waitForPostgres(containerID string) error {
    timeout := v.config.ContainerReadyTimeout
    if timeout == 0 {
        timeout = DefaultContainerReadyTimeout
    }

    for retry := 0; retry < MaxRetries; retry++ {
        if retry > 0 {
            time.Sleep(RetryBackoff * time.Duration(retry))
        }

        // Test connection with pg_isready
        cmd := exec.Command("docker", "exec", containerID,
            "pg_isready", "-U", "postgres")

        deadline := time.Now().Add(timeout)
        for time.Now().Before(deadline) {
            if err := cmd.Run(); err == nil {
                return nil  // Success
            }
            time.Sleep(1 * time.Second)
        }
    }

    return fmt.Errorf("timeout waiting for PostgreSQL after %v with %d retries",
        timeout, MaxRetries)
}
```

#### Verification Plan
1. Update configuration to use 90s timeout
2. Add retry logic with exponential backoff
3. Test against all 3 projects
4. Verify validation completes successfully
5. Document recommended timeout values for different project sizes
