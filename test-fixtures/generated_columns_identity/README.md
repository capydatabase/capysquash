# Generated Columns and Identity Test Fixture

This fixture tests handling of PostgreSQL generated columns and identity columns in migration consolidation.

## PostgreSQL Versions Tested

- **IDENTITY columns**: PostgreSQL 10+
- **GENERATED columns**: PostgreSQL 12+
- **Virtual generated columns**: PostgreSQL 15+

## Scenarios Tested

- **IDENTITY columns**: `GENERATED BY DEFAULT AS IDENTITY` vs `GENERATED ALWAYS AS IDENTITY`
- **Generated columns**: `GENERATED ALWAYS AS (...) STORED` with various expressions
- **Complex expressions**: CASE statements, mathematical operations, function calls
- **Dependencies**: Indexes on generated columns, constraints involving generated columns
- **SERIAL compatibility**: Handling legacy SERIAL columns alongside modern IDENTITY

## Migration Files

1. **001_create.sql**: Basic IDENTITY and GENERATED columns with indexes
2. **002_generated.sql**: Complex expressions and cross-table references
3. **003_advanced.sql**: Virtual columns, constraints, and edge cases

## Expected Behavior

- **Paranoid mode**: Preserves exact IDENTITY and GENERATED syntax
- **Conservative mode**: Consolidates similar patterns, preserves version-specific features
- **Standard mode**: Normalizes expressions, consolidates compatible patterns
- **Aggressive mode**: Merges tables, preserves all generated column dependencies

## Edge Cases

- Complex expressions with CASE statements and function calls
- Constraints that reference generated columns
- Indexes on generated columns with specific opclasses
- JSON path expressions in generated columns
- SERIAL to IDENTITY conversion scenarios
